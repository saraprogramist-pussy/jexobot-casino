TAJIK WIN v2 — КАК ЗАПУСТИТЬ ЧЕРЕЗ GITHUB + RENDER

1. Распакуй ZIP на компьютере.
2. Открой свой GitHub-репозиторий. Если это старая версия JEXOBOT, сделай резервную копию старого проекта.
3. Загрузить содержимое архива (app.py, db.py, server.py, games.py, games_extra.py, requirements.txt, render.yaml и папку webapp) непосредственно В КОРЕНЬ репозитория. Не загружай внешнюю папку TajikWin_v2 как единый уровень.
4. Проверь, что requirements.txt находится рядом с app.py в корне GitHub.
5. В Render открой сервис -> Settings:
   Root Directory: пусто
   Build Command: pip install -r requirements.txt
   Start Command: python app.py
6. В Render -> Environment добавь:
   BOT_TOKEN    = токен из @BotFather
   ADMIN_ID     = свой числовой Telegram ID
   WEBAPP_URL   = https://<имя-сервиса>.onrender.com
   PYTHON_VERSION = 3.12.9
7. Нажми Deploy latest commit. После статуса Live проверь https://<имя-сервиса>.onrender.com/health.
8. В Telegram отправь боту /start, затем открой Mini App.
9. Админ-команды: /admin, /promo TAJIK50 50000 20, /give ID 50000, /requests, /reply ID текст.
10. Если появилась ошибка, пришли последние строки логов Render (без токенов).

Важно: бесплатный Render использует эфемерную файловую систему — SQLite может терять данные после рестартов и деплоев. Для сохранения балансов нужен постоянный диск/внешняя база. Реальные платежи и вывод денег не поддерживаются.
