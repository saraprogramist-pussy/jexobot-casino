# TAJIK WIN v2 — Telegram Mini App

Игровое Telegram Mini App с условными кредитами. **Реальные деньги, платёжные системы, вывод средств и обмен кредитов на деньги не поддерживаются.** В приложении отображается «Баланс»; условия использования игрового баланса указаны на главном экране. Шлюз начислений предназначен только для администраторских выдач игровых кредитов.

## Содержимое

- 12 игровых механик: Slots, Roulette, Dice, Blackjack, Crash, Mines, Plinko, Keno, Wheel, Hi-Lo, Video Poker (без замены карт), Tower.
- Ставка: 3 000–1 000 000 UZS. Шесть быстрых ставок: 10 000 / 100 000 / 200 000 / 300 000 / 400 000 / 500 000.
- Новый интерфейс на тёмной/золотой/бордовой палитре: 12 индивидуальных SVG-иллюстраций игр, отдельный векторный логотип, индивидуальные CSS-анимации игровых сцен и оригинальные синтезированные звуки. Звук зачисления — краткая трёхнотная последовательность.
- История ставок с закреплением и скрытием (сам аудиторский журнал сохраняется).
- Личный профиль: никнейм, встроенный аватар, языки RU/UZ/EN (основные подписи; тексты описаний игр сейчас по-русски), включение звука, отображение UZS/USD/EUR/RUB.
- Курсы валют: запрос к API Центрального банка Узбекистана. Если актуальные курсы недоступны, приложение не придумывает коэффициенты; в этом случае отображается UZS.
- Промокоды: одно использование кода на игрока, лимит активаций.
- Базовые VIP-уровни Bronze/Silver/Gold по общей сумме ставок и недельный рейтинг игроков (без денежных наград).
- Заявки на **начисление игровых кредитов**: администратор получает сообщение с кнопками Одобрить/Отклонить/Ответить; повторное нажатие не начисляет деньги вторично.
- Обращения в поддержку: текст из Mini App, скриншоты из чата с Telegram-ботом.

## Первый запуск

### Шаг 1. Создайте Telegram-бота

В @BotFather создайте бота и возьмите BOT_TOKEN. Не публикуйте токен и не помещайте его в исходники.

### Шаг 2. Подготовьте переменные окружения

- `BOT_TOKEN` — токен Telegram-бота.
- `ADMIN_ID` — ваш числовой Telegram ID; узнать можно `/myid`.
- `WEBAPP_URL` — публичный HTTPS URL опубликованного приложения, например `https://your-service.onrender.com`.
- `PORT` — порт сервера, локально по умолчанию 8000.
- `DB_PATH` — необязательный путь к файлу SQLite, например `/data/tajikwin.sqlite` при наличии **постоянного** диска.

### Шаг 3. Разверните на Render

1. Поместите **содержимое папки TajikWin, а не саму папку**, в корень репозитория GitHub.
2. В Render укажите Root Directory пустым, Build Command `pip install -r requirements.txt`, Start Command `python app.py`.
3. Установите Python 3.12 (файл `render.yaml` содержит `PYTHON_VERSION`).
4. Добавьте переменные окружения. `WEBAPP_URL` должен соответствовать вашему URL Render.
5. После изменения переменных перезапустите сервис. Напишите Telegram-боту `/start`, откройте Mini App.

**ВАЖНО о Render Free:** локальная SQLite-база на бесплатном эфемерном сервере может исчезать при пересборке/рестарте; для надёжной многопользовательской эксплуатации нужен постоянный диск либо перенос на управляемую БД (например PostgreSQL). Эта версия использует SQLite и не предназначена для масштабирования на несколько процессов. Не используйте её для денежных расчётов.

Для локального тестирования веб-части: `pip install -r requirements.txt`, затем `python app.py`. Для запуска непосредственно через Telegram требуется публичный HTTPS-туннель и актуальный `WEBAPP_URL`. Прямое открытие браузером без Telegram `initData` покажет интерфейс, но не разрешит ставки.

## Команды администратора

| Команда | Действие |
|---|---|
| `/myid` | Telegram ID |
| `/admin` | Краткая статистика и команды |
| `/promo TAJIK50 50000 100` | Промокод на 50 000 условных сумов, 100 активаций |
| `/give 123456789 100000` | Вручную начислить условные сумы пользователю |
| `/give 123456789 -10000` | Уменьшить баланс на 10 000 (не ниже 0) |
| `/requests` | Последние заявки на начисления |
| `/reply 123456789 Привет` | Ответить пользователю через бота |
| `/top` | Рейтинг игроков |

Раздел `/broadcast` оставлен **отключённым** до реализации подтверждённого согласия на уведомления.

## Важные технические границы

- Каждый пользовательский API-запрос проверяет подпись Telegram `initData`, а операции с балансом выполняются в SQLite-транзакции.
- Игра с активной сессией блокирует запуск других ставок до завершения.
- Игровые результаты генерируются на сервере через `random.SystemRandom`. Это не сертифицированная платформа с проверяемой честностью (`provably fair`), не аудит вероятностей для регулируемого гемблинга.
- Для Blackjack реализованы упрощённые правила без сплита, удвоения и страховки; для Video Poker — одна раздача без обмена; Tower — модель вероятностей по уровням. Математика ставок и выплаты описаны в исходниках.
- Базовые клубные уровни Bronze/Silver/Gold и недельный рейтинг по сумме ставок включены. Турниры с календарём, отдельными правилами и раздачей призов, собственная загрузка фото профиля и полный перевод правил **пока не реализованы**.
- Заявки и переписка не заменяют платёжный процесс и не должны использоваться для сбора подтверждений реальных денежных переводов.

## Проверки

В папке проекта выполнить: `python -m unittest -v test_project.py`. Включены тесты игрового API, авторизации, ограничений ставок, истории, промокодов и запрета двойного начисления.

## Изменения визуальной версии v2

- `webapp/assets/` содержит 12 собственных SVG-иллюстраций; плитки игр больше не используют эмодзи или стикеры.
- `webapp/premium.css` задаёт новый адаптивный дизайн чёрный / бордовый / золото / зелёные результаты.
- Для Slots, Roulette, Dice, Blackjack, Crash, Mines, Plinko, Keno, Wheel, Hi-Lo, Poker и Tower предусмотрены раздельные сценические анимации (для Mines/Keno — эффекты открытия и подсветки). Все эффекты визуальные; исход раунда определяется на сервере.
- Синтезатор Web Audio создаёт оригинальные сигналы запуска, отдельных игр, выигрыша, проигрыша и начисления; воспроизведение звука может требовать первого пользовательского касания.
- Результат из браузерного предпросмотра без Telegram-подписи не даёт проводить ставки.
- Для production необходимы отдельное тестирование Telegram WebView на iOS/Android, постоянное хранилище БД и резервное копирование.
- После публикации лучше удалить старый кэш Mini App: обновить страницу или открыть бота заново.
