# Tajik Win — новая версия Telegram Mini App

**Назначение:** игровой Telegram Mini App на внутренних невыводимых кредитах. **Не принимает платежи, не выплачивает реальные деньги.** В интерфейсе отображается «Баланс»; пояснение о статусе кредитов есть в правилах клуба.

Это **функциональная тестовая сборка**, а не прошедшая сертификацию казино-платформа. Математические модели являются исходным кодом и подлежат независимому аудиту перед коммерческой эксплуатацией.

## Возможности

- 12 игр: Slots, Roulette, Dice, Blackjack, Crash, Mines, Plinko, Keno, Wheel, Hi-Lo, Video Poker, Tower.
- Нулевой баланс при регистрации нового Telegram-пользователя.
- Ставки в диапазоне 3 000–1 000 000 UZS; кнопки +10K/+50K/+100K/+200K накапливают сумму.
- Отображение UZS/USD/RUB/EUR по ЦБ Узбекистана, если API доступен. Учёт всегда в UZS.
- Каждая игра имеет отдельную логику и анимацию; показываемый исход следует серверному результату.
- Crash: общий серверный цикл: 7 секунд для ставок, затем коэффициент до 21×; общие раунды не зависят от числа игроков и браузеров. Есть ручной/автоматический вывод.
- Игровые сессии Blackjack/Mines/Hi-Lo/Poker/Tower сохраняются в SQLite; скрытые позиции мин и колода не выдаются клиенту.
- Промокоды, история ставок, ручные заявки на начисление, сообщения/скриншоты администратору.
- Кнопка «Правила» на каждом игровом экране.
- 7 утверждённых звуков пользователя (MP3) и 14 новых оригинальных коротких звуков (WAV).

## Запуск локально

Python 3.11–3.14:

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен BotFather"
export ADMIN_ID="ваш_telegram_id"
export WEBAPP_URL="https://домен-вашего-сервера"
python app.py
```

Для Windows PowerShell вместо `export` используйте `$env:BOT_TOKEN="..."` и аналогично для остальных.

**Локальная проверка API:** только на машине разработчика можно запустить `LOCAL_TEST=1 uvicorn server:app --port 8000` и передавать `initData=test:12345`. **Никогда не включайте `LOCAL_TEST=1` в Render или другом публичном сервисе:** это отключает реальную Telegram-проверку для тестовых ID.

## GitHub + Render

1. Создайте отдельную папку/ветку в GitHub. Загрузите **содержимое** `TajikWin_Rebuild` в папку `TajikWin_Rebuild` вашего репозитория. Не заливайте `.env`, токены или локальную БД.
2. Откройте сервис Render → **Settings** → **Root Directory:** `TajikWin_Rebuild`.
3. **Build Command:** `pip install -r requirements.txt`.
4. **Start Command:** `python app.py`.
5. **Environment:** задайте `BOT_TOKEN`, `ADMIN_ID`, `WEBAPP_URL` (например `https://jexobot-casino.onrender.com`), **не задавайте `LOCAL_TEST`**.
6. Сохраните настройки → **Manual Deploy → Deploy latest commit**. После «Live» откройте бота и отправьте `/start`.
7. Для работы кнопки Mini App нужен HTTPS, подходящий Telegram. Можно настроить домен в BotFather.

**ВНИМАНИЕ — Render Free:** бесплатный сервер засыпает, а локальная SQLite-база на эфемерном диске **может потеряться после деплоя или перезапуска**. Непрерывные Crash-раунды не смогут продолжаться, пока бесплатный сервер спит. Для реальной эксплуатации требуются постоянно работающий сервер и **постоянная база данных** (например PostgreSQL после миграции). Не заводите реальные пользовательские балансы на Render Free с SQLite. Для демонстрационного теста работает.

**Серверная масштабируемость:** пока одна задача Crash на процесс. Запускайте только один процесс/инстанс; горизонтальное масштабирование требует выделенного планировщика и межпроцессной синхронизации. `WEB_CONCURRENCY=1`.

## Команды в Telegram

| Команда | Кто | Действие |
|---|---|---|
| `/start` | игрок | открыть приложение |
| `/myid` | игрок | показать ID |
| `/top` | игрок | рейтинг по балансу |
| `/admin` | админ | перечень команд |
| `/requests` | админ | последние заявки |
| `/approve 123abc` | админ | одобрить заявку один раз |
| `/reject 123abc` | админ | отклонить заявку |
| `/give 123456789 100000` | админ | выдать 100 000 игровых сумов |
| `/promo START 50000 25` | админ | код на 50 000, 25 активаций |
| `/reply 123456789 Привет` | админ | ответить игроку |

Игрок может написать сообщение или прислать скриншот боту — бот перенаправит администратору.

## Аудиофайлы

В `webapp/sounds/`:

- `credit.mp3` — выбранный пользователем сигнал пополнения;
- `roulette.mp3` — обрезанный выбранный звук вращения рулетки;
- `dice.mp3` — новый выбранный звук костей **без обрезки**;
- `bet.mp3` — размещение фишки, `chips.mp3` — перебирание фишек;
- `shuffle.mp3` — тасовка карт;
- `jackpot.mp3` — джекпот;
- отдельные `*_fx.wav` — короткие оригинальные вспомогательные эффекты для всех 12 игр и победы/поражения.

Сигнал успешного начисления воспроизводится после прихода события в API, а не при отправке заявки. В iOS/Android звук зависит от разрешений WebView и первого взаимодействия пользователя с приложением.

## Математика и ограничения текущей версии

- Рулетка — европейская, RNG (не общая live-рулетка).
- Blackjack — Hit/Stand, дилер до 17, **без Split/Double и без бонусной выплаты за натуральный blackjack**. Эти правила отражены во всплывающей справке.
- Poker — видеопокер, один обмен, без дополнительных раундов.
- Keno — 1–10 выбранных чисел из 40, десять случайных результатов; таблица выплат вычисляется по гипергеометрическому распределению, приблизительный RTP 96%.
- Slot — три символа, фиксированные веса/комбинации. Дополнительные линии, free spins и scatter не добавлены.
- Crash — максимальный коэффициент 21×, независимые раунды, целевая модель RTP близка к 96%, округление может влиять на точное значение.
- Все игровые выплаты и вероятности доступны в `engine.py`. Не заявляйте сертифицированный RTP или provably fair без внешней проверки.
- Анимации текущей сборки реализованы CSS/JavaScript, а не 3D-движком. Для киношного уровня оригинальных казино потребуются отдельные игровые анимационные ассеты и тестирование на устройствах.

## Тестирование

```bash
python -m unittest -v test_project
node --check webapp/app.js
```

Тесты проверяют 12 игровых API/движков, нулевой начальный баланс, ограничения ставок, промокоды, заявки, сохранность баланса и Crash. Перед запуском в Telegram нужно дополнительно проверить реальные звуки, WebView, мобильную производительность и возобновление сеансов после сети/перезапуска.

## Структура

- `engine.py`: математика 12 игр, подготовка/розыгрыш результатов.
- `storage.py`: SQLite, атомарные ставки, баланс, сессии, промокоды, заявки и Crash-раунды.
- `server.py`: FastAPI API, проверка `initData`, общий цикл Crash.
- `app.py`: aiogram Telegram bot + uvicorn.
- `webapp/`: Modern Bet интерфейс, SVG-иллюстрации, звук и анимация.
- `test_project.py`: тесты игрового движка.
