# Demo Casino — Telegram Mini App

Красивое мини-приложение внутри Telegram: баланс, слоты, рулетка, кости, блэкджек,
таблица лидеров. Виртуальная валюта, реальные деньги не используются.
Плюс команда для ведущего — выдавать сумы игрокам вручную.

## Что изменилось по сравнению с первой версией

Раньше игры были кнопками прямо в чате. Теперь при `/start` бот присылает
одну кнопку **"Открыть Casino"**, которая открывает полноценную страницу
внутри Telegram — со своим дизайном, без "простыни" сообщений в чате.

## Шаг 1. Установи зависимости

```
pip install -r requirements.txt
```

## Шаг 2. Узнай свой Telegram ID (чтобы стать админом)

1. Запусти бота один раз без ADMIN_ID (см. шаг 4), напиши ему `/myid`
2. Бот пришлёт твой числовой ID — сохрани его, понадобится дальше

## Шаг 3. Установи ngrok (для тестовой HTTPS-ссылки)

Telegram требует, чтобы Mini App открывался по HTTPS-адресу, доступному из интернета.
ngrok бесплатно даёт такой адрес для сервера на твоём компьютере.

1. Зайди на https://ngrok.com, зарегистрируйся (бесплатно)
2. Скачай ngrok для Windows, распакуй `ngrok.exe` в ту же папку с ботом
3. На сайте ngrok в разделе "Your Authtoken" скопируй свой токен
4. В PowerShell, в папке с ботом, выполни один раз:
   ```
   .\ngrok.exe config add-authtoken ТВОЙ_ТОКЕН_С_САЙТА
   ```

## Шаг 4. Первый запуск — получить ссылку

Открой **два** окна PowerShell в папке с ботом.

**Окно 1** — запусти сервер (пока без ссылки, только чтобы работал порт 8000):
```
$env:BOT_TOKEN="твой_токен_бота"
python app.py
```

**Окно 2** — запусти ngrok, направленный на этот же порт:
```
.\ngrok.exe http 8000
```

Ngrok покажет строку вида:
```
Forwarding    https://a1b2-xx-xx-xx-xx.ngrok-free.app -> http://localhost:8000
```

Скопируй этот `https://...ngrok-free.app` адрес — это и есть ссылка на твоё приложение.

## Шаг 5. Перезапусти с полной настройкой

Останови бота в Окне 1 (`Ctrl+C`), затем запусти снова, уже со всеми переменными:

```
$env:BOT_TOKEN="твой_токен_бота"
$env:ADMIN_ID="твой_telegram_id_из_шага_2"
$env:WEBAPP_URL="https://a1b2-xx-xx-xx-xx.ngrok-free.app"
python app.py
```

Окно 2 с ngrok должно остаться запущенным параллельно — не закрывай его.

Теперь напиши боту `/start` — должна появиться кнопка "Открыть Casino", и при
нажатии откроется красивое мини-приложение.

⚠️ **Важно:** при каждом перезапуске ngrok (бесплатная версия) ссылка меняется.
Значит после перезапуска нужно будет заново обновить `WEBAPP_URL` новой ссылкой
и перезапустить `app.py`. Для фиксированной ссылки нужен платный ngrok
или деплой на постоянный хостинг (см. раздел ниже).

## Как выдать баланс другу (ты — ведущий)

1. Друг должен **один раз написать `/start`** твоему боту — иначе бот его не знает
2. Ты узнаёшь его username (то, что после @ в Telegram) или просишь прислать `/myid`
3. Пишешь в чате с ботом (не в общем чате — лично боту):
   ```
   /give @username_друга 1000
   ```
   или по ID:
   ```
   /give 123456789 1000
   ```
4. Другу придёт уведомление о начислении, у тебя — подтверждение

Команда `/give` работает только у тебя — у того, чей Telegram ID указан в `ADMIN_ID`.

## Другие команды бота

- `/myid` — узнать свой Telegram ID
- `/top` — таблица лидеров прямо в чате

## Постоянный хостинг (без ngrok, 24/7)

Когда наиграетесь с тестовой версией и захотите, чтобы бот работал всегда,
не держа компьютер включённым — можно бесплатно задеплоить на Render.com
или Railway.app как обычное Python-приложение (команда запуска: `python app.py`,
порт берётся из переменной `PORT`, которую они задают сами). Там же задаются
`BOT_TOKEN`, `ADMIN_ID` и `WEBAPP_URL` (туда впишешь постоянный адрес,
который даст сам хостинг) в настройках проекта. Если дойдёшь до этого шага —
просто напиши, помогу с конкретной платформой.

## Структура проекта

- `app.py` — точка входа: бот + веб-сервер вместе
- `server.py` — API для мини-приложения, проверка подлинности Telegram-запросов
- `db.py` — хранилище (SQLite): балансы, история ставок, бонусы
- `games.py` — логика игр (RNG)
- `webapp/index.html` — сама страница мини-приложения

## Важно

- Это **не** платформа с реальными деньгами — не добавляй пополнение или вывод
  через платёжные системы, это сделает проект незаконным нелицензированным гемблингом.
- Не показывай токен бота никому — если он "засветился" в переписке, перегенерируй
  его у @BotFather командой `/revoke`.
