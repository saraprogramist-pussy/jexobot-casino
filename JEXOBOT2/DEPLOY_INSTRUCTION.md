## ШАГ 4: Регистрация на Render.com (3 минуты)

1. Откройте https://render.com
2. Нажмите **Get Started for Free**
3. Выберите **Sign up with GitHub**
4. Разрешите Render доступ к вашему GitHub
5. Подтвердите email от Render

---

## ШАГ 5: Создание Web Service на Render (10 минут)

1. В Render нажмите **New +** → **Web Service**
2. Нажмите **Connect a repository**
3. Найдите и выберите `jexobot-casino`
4. Заполните настройки:
   - **Name:** `jexobot-casino` (или любое название)
   - **Region:** выберите ближайший (Europe - Frankfurt)
   - **Branch:** `main`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python app.py`
   - **Instance Type:** `Free`

5. Нажмите **Advanced** и добавьте переменные окружения:

   Нажмите **Add Environment Variable** 4 раза и добавьте:

   | Key | Value |
   |-----|-------|
   | `BOT_TOKEN` | ваш_токен_бота_от_BotFather |
   | `ADMIN_ID` | ваш_telegram_id |
   | `PORT` | `10000` |
   | `WEBAPP_URL` | https://jexobot-casino.onrender.com |

   **ВАЖНО:** В `WEBAPP_URL` замените `jexobot-casino` на название, которое вы указали в поле Name

6. Нажмите **Create Web Service**

---

## ШАГ 6: Получение URL и обновление WEBAPP_URL

1. После создания, Render начнет деплой (займет 3-5 минут)
2. Вверху страницы появится ваш URL: `https://ваше-название.onrender.com`
3. Скопируйте этот URL
4. Перейдите в **Environment** (слева в меню)
5. Найдите переменную `WEBAPP_URL` и нажмите на неё
6. Вставьте скопированный URL
7. Нажмите **Save Changes**
8. Render автоматически перезапустит бота
