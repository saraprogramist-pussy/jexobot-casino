# ЧАСТЬ 1: ЗАГРУЗКА НА GITHUB (10 минут)

## ШАГ 1: Регистрация/вход на GitHub

**Если у вас НЕТ аккаунта GitHub:**

1. Откройте https://github.com
2. Нажмите **Sign up** (зеленая кнопка справа вверху)
3. Введите:
   - Email (ваш настоящий email)
   - Пароль (придумайте надежный)
   - Username (любое имя, например: muzaffar-dev)
4. Решите капчу
5. Нажмите **Create account**
6. Зайдите в ваш email и подтвердите регистрацию (нажмите на ссылку в письме)

**Если у вас УЖЕ ЕСТЬ аккаунт GitHub:**

1. Откройте https://github.com
2. Нажмите **Sign in**
3. Введите логин и пароль

---

## ШАГ 2: Создание нового репозитория

1. После входа в GitHub нажмите кнопку **"+"** (плюс) в правом верхнем углу
2. Выберите **"New repository"**
3. Заполните форму:

   ```
   Repository name: jexobot-casino
   
   Description: Telegram Casino Bot (Mini App)
   
   ⚪ Public (выберите Public - публичный)
   
   ✅ Add a README file (поставьте галочку)
   ```

4. Нажмите зеленую кнопку **"Create repository"**

---

## ШАГ 3: Загрузка файлов проекта

1. Вы окажетесь на странице вашего нового репозитория
2. Нажмите кнопку **"Add file"** → выберите **"Upload files"**
3. Откройте проводник Windows (Win + E)
4. Перейдите в папку: `C:\Users\Muzaffar\Desktop\JEXOBOT2`
5. Выделите ВСЕ файлы и папки (нажмите Ctrl + A)
6. Перетащите их в окно браузера (на GitHub)
7. В поле "Commit changes" внизу напишите: `Initial upload`
8. Нажмите зеленую кнопку **"Commit changes"**
9. ⏳ Подождите 1-2 минуты, пока файлы загрузятся

✅ **Готово! Код теперь на GitHub**

# ЧАСТЬ 2: DEPLOY НА RENDER.COM (5-10 минут)

## ШАГ 4: Регистрация на Render.com

1. Откройте https://render.com
2. Нажмите **"Get Started for Free"**
3. Выберите **"Sign up with GitHub"** (войти через GitHub)
4. Разрешите Render доступ к вашему GitHub (нажмите зеленую кнопку)
5. Откройте ваш email и подтвердите регистрацию на Render

---

## ШАГ 5: Создание Web Service

1. В Render нажмите синюю кнопку **"New +"** (вверху справа)
2. Выберите **"Web Service"**
3. Нажмите **"Connect a repository"** или **"Build and deploy from a Git repository"**
4. Найдите в списке **jexobot-casino** и нажмите **"Connect"**

---

## ШАГ 6: Настройка проекта

Заполните форму:

### Basic Settings:

```

(или любое название, оно будет в URL)

Region: Frankfurt (EU Central)
(выберите ближайший к вам регион)

Branch: main

Root Directory: (оставьте пустым)

Start Command: python app.py
```

### Instance Type:


## ШАГ 7: Добавление переменных окружения (Environment Variables)

Прокрутите вниз до раздела **"Environment Variables"**

Нажмите **"Add Environment Variable"** и добавьте 4 переменные:

### Переменная 1:
```
Key: BOT_TOKEN
Value: (вставьте токен вашего бота от BotFather)
```

### Переменная 2:
```
Key: ADMIN_ID
Value: (ваш Telegram ID, узнать можно у бота @userinfobot)
```

### Переменная 3:
```
Key: PORT
Value: 10000
```

### Переменная 4:
```
Key: WEBAPP_URL
Value: https://jexobot-casino.onrender.com
```

⚠️ **ВАЖНО!** В `WEBAPP_URL` замените `jexobot-casino` на то название, которое вы указали в поле **Name** на шаге 6!

Например, если вы назвали `my-casino-bot`, то URL будет:
```
https://my-casino-bot.onrender.com
```

---

## ШАГ 8: Запуск деплоя

1. Нажмите зеленую кнопку **"Create Web Service"** внизу страницы
2. ⏳ Render начнет сборку и деплой (это займет 3-5 минут)
3. Вы увидите логи сборки - это нормально
4. Дождитесь, пока статус изменится на **"Live"** (зеленый)

---

## ШАГ 9: Получение финального URL

1. После успешного деплоя, вверху страницы появится ваш URL
2. Он будет выглядеть так: `https://ваше-название.onrender.com`
3. **Скопируйте этот URL полностью!**

---

## ШАГ 10: Обновление WEBAPP_URL (ВАЖНО!)

Если URL, который дал Render, отличается от того, что вы указали:

1. В меню слева нажмите **"Environment"**
2. Найдите переменную `WEBAPP_URL`
3. Нажмите на карандашик (Edit)
4. Вставьте ПРАВИЛЬНЫЙ URL (который скопировали на шаге 9)
5. Нажмите **"Save Changes"**
6. Render автоматически перезапустит бота (подождите 1-2 минуты)

1. Зайдите в Render → ваш проект → **Logs**
2. Посмотрите последние строки логов
3. Если есть ошибка - скопируйте и пришлите мне

## Если кнопка "Открыть Casino" не работает:

1. Проверьте, что `WEBAPP_URL` указан правильно
2. Убедитесь, что URL начинается с `https://` и заканчивается на `.onrender.com`
3. Проверьте, что токен бота действительный

## Если Render показывает ошибку при деплое:

1. Проверьте, что все файлы загрузились на GitHub
2. Убедитесь, что `requirements.txt` присутствует
3. Проверьте логи сборки (Build Logs)
