# JEXOBOT — Telegram Mini App

Готовый пример Telegram Mini App с шестью играми, виртуальными монетами и промокодами. **Это развлекательный демо-проект: монеты не являются деньгами и не обмениваются на ценности.** Пополнение, вывод и платёжные системы отсутствуют.

## Функции

- Слоты (3 барабана), рулетка (цвет/чётность/число), кости (1–6)
- Blackjack (взять карту / остановиться), Crash (живой множитель / забрать), Mines (5×5 / забрать)
- Защита Telegram initData; статистика и рейтинг
- Начальный баланс — **100 000 виртуальных монет** каждому новому игроку
- **Нет ежедневного бонуса**. Вместо него — промокоды, создаваемые администратором
- Один промокод активируется одним игроком только раз, число активаций задаёт администратор
- Денежные операции со ставками защищены транзакциями SQLite; активные игровые раунды переживают перезапуск сервера

## Установка на Windows

Python 3.11+ (или совместимая версия):

```powershell
cd C:\path\to\JEXOBOT
python -m pip install -r requirements.txt
```

Создай Telegram-бота у `@BotFather`, получи токен и **не публикуй его**.

В Telegram-боте команда `/myid` покажет твой Telegram ID (доступна при работе бота). Для первого запуска можешь указать ADMIN_ID=0.

Для Telegram Mini App нужна публичная **HTTPS-ссылка** (например, через ngrok). Запусти в другом окне:

```powershell
ngrok http 8000
```

Скопируй адрес вида `https://...ngrok-free.app` и запусти проект:

```powershell
$env:BOT_TOKEN="<токен от BotFather>"
$env:ADMIN_ID="<твой числовой Telegram ID>"
$env:WEBAPP_URL="https://...ngrok-free.app"
python app.py
```

В чате Telegram-бота набери `/start` → «Открыть JEXOBOT». Убедись, что ссылка HTTPS доступна и приложение запущено через **Telegram**, иначе запросы API не пройдут проверку подписи.

### Промокоды

Администратор (`ADMIN_ID`) создаёт промокод в чате бота:

```text
/promo WELCOME50 50000 100
```

Это создаст код `WELCOME50`: **50 000 виртуальных монет**, максимум **100 активаций**. Игроки вводят код на главном экране Mini App. Принимаются только латинские буквы, цифры, `_` и `-` (3–32 символа). Повторное использование одним игроком запрещено. Ранее созданный код не перезаписывается.

Остальные команды: `/myid`, `/top`, `/give <username или ID> <сумма>` (последняя только для администратора).

### Локальная проверка интерфейса

После запуска приложения открой `http://localhost:8000/` в браузере. Вне Telegram появится предупреждение, что авторизация недоступна. Чтобы тестировать реальные операции, открывай мини-приложение из Telegram.

### Проверка API

```powershell
python -m unittest -v test_project.py
```

## Файлы

- `app.py` — Telegram-бот и запуск FastAPI
- `server.py` — защищённое API для Mini App
- `db.py` — SQLite, транзакции, ставки, сохранённые сессии и промокоды
- `games.py` — логика и генерация случайных результатов
- `webapp/index.html`, `style.css`, `app.js` — интерфейс Mini App
- `test_project.py` — автоматические проверки API

## Перед публикацией

- Не добавляй в исходники токен от BotFather. Используй переменные окружения.
- Для постоянного хостинга нужна **постоянная база SQLite на подключённом диске** (через `DB_PATH`) или переход на полноценную СУБД. **На Render без persistent disk сохранённые балансы и промокоды могут исчезнуть при перезапуске или новом деплое.**
- Рассчитывай на один процесс сервера с polling. Если запустить одновременно два экземпляра бота с одним токеном, Telegram polling будет конфликтовать.
- В проекте демо-генераторы случайных результатов; он **не является сертифицированной азартной платформой**. Реальные деньги не поддерживаются.
- При изменении алгоритмов или дальнейшей разработке нужны дополнительные тесты интерфейса и проверка безопасности перед публичным запуском.
