TAJIK WIN v3 — УСТАНОВКА НА GITHUB И RENDER

1. Открой GitHub репозиторий jexobot-casino.
2. Загрузите содержимое папки TajikWin_v3 (app.py, server.py, requirements.txt, webapp и другие), а не папку целиком. Если старая папка v2 остаётся в репозитории, допустимо загрузить v3 в собственную папку TajikWin_v3 и указать Root Directory именно TajikWin_v3.
3. Render → сервис → Settings → Root Directory: TajikWin_v3 (если загрузили папку) или пустое поле (если загрузили файлы в корень).
4. Build Command: pip install -r requirements.txt
5. Start Command: python app.py
6. Environment: BOT_TOKEN, ADMIN_ID, WEBAPP_URL=https://ВАШ-СЕРВИС.onrender.com
7. Manual Deploy → Deploy latest commit. Откройте /health и /start в боте.

ВАЖНО: на Render Free SQLite без постоянного диска может потерять данные. Реальные деньги не используются.
